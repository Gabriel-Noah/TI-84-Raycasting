# Raycasting for Ti84
Raycasting on the Ti84 using the [CE C/C++ Toolchain](https://ce-programming.github.io/toolchain/index.html)

https://github.com/user-attachments/assets/6371a441-8084-4a43-acff-b01899e875e7


## Controls
Up and down to move forwards and backwards.  
Left and right to rotate.  
mode or clear to exit.  

## Build instructions
1. Install the [CE C/C++ Toolchain](https://ce-programming.github.io/toolchain/static/getting-started.html)
2. Run make inside of the project folder
